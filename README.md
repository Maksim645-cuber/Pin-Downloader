Pinterest Video Downloader

Маленький сайт, который запускается на вашем компьютере и скачивает видео из Pinterest. Вы вставляете код для встраивания пина, нажимаете кнопку и получаете видео в формате mp4.

Как пользоваться
Откройте видео-пин в Pinterest.
Нажмите «…» и выберите «Получить код для встраивания пина».
Скопируйте код. Он выглядит примерно так:
html
<iframe src="https://assets.pinterest.com/ext/embed.html?id=1234567890123456789" height="445" width="345" frameborder="0" scrolling="no"></iframe>
Вставьте его на сайте, нажмите «Найти видео», затем «Скачать видео».

Вместо кода можно вставить обычную ссылку на пин или короткую ссылку pin.it/....

Установка

Понадобится Python версии 3.10 или новее. Проверить версию можно командой python --version (на macOS и Linux это python3 --version).

bash
git clone https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git
cd ИМЯ_РЕПОЗИТОРИЯ
pip install -r requirements.txt
python app.py

Когда в терминале появится строка Running on http://127.0.0.1:5000, откройте в браузере http://127.0.0.1:5000.

Пока окно терминала открыто, сайт работает. Остановить его можно сочетанием Ctrl+C.

Красное предупреждение This is a development server появляется всегда и не означает ошибку. Сайт рассчитан на запуск у вас на компьютере.

Из чего состоит проект
├── app.py              сервер: ищет видео и отдаёт файл
├── requirements.txt    зависимости (Flask, requests)
└── templates/
    └── index.html      страница сайта

Файл index.html должен лежать в папке templates рядом с app.py.

Как это работает

В коде встраивания самого видео нет, там только ID пина. Сервер достаёт этот ID, запрашивает у Pinterest данные пина, находит прямую ссылку на mp4 и отдаёт файл браузеру. Скачивать через сервер можно только файлы с серверов Pinterest (*.pinimg.com), поэтому он не работает как открытый прокси.

Запускать сайт нужно именно через app.py. Если открыть index.html двойным щелчком или через Live Server, поиск видео работать не будет: ему нужна Python-часть.

Если что-то не работает
Что вы видите	Что делать
«Эта страница открыта не через app.py» или ошибка 404	Запустите python app.py и откройте именно http://127.0.0.1:5000, а не файл или Live Server
python не найден	На Windows попробуйте py app.py, на macOS и Linux python3 app.py
Ошибка про синтаксис или тип str | None	Версия Python старше 3.10, обновите её
Порт 5000 занят (часто на macOS из-за AirPlay)	В последней строке app.py замените на app.run(debug=True, port=5001) и откройте http://127.0.0.1:5001
«Внутренняя ошибка сервера: не найден index.html»	Положите index.html в папку templates рядом с app.py
«В этом пине нет видео»	Проверьте, что это именно видео-пин. Если видео точно есть, Pinterest мог изменить формат ответа, см. ниже
Видео не находится, хотя оно есть

Pinterest время от времени меняет внутренние ответы, и тогда поиск может перестать работать. В терминале с app.py появятся строки со словами «не сработал». Создайте Issue и приложите эти строки без личных данных. Так проще всего понять, что поменялось.

Важно
Скачивайте видео для личного использования. Права на ролики принадлежат их авторам, не публикуйте чужие работы без разрешения.
Проект не связан с Pinterest и не одобрен компанией. Использование может нарушать её условия сервиса, ответственность за это на вас.
Не выкладывайте сервер в интернет в таком виде: в app.py включён режим отладки (debug=True), он предназначен только для локального запуска. Для публичного хостинга уберите его и используйте продакшен-сервер, например gunicorn.
