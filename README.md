Pinterest Video Downloader

Маленький сайт для запуска на вашем компьютере, который скачивает видео из Pinterest в формате MP4.

Вы вставляете код для встраивания пина, нажимаете кнопку и получаете ссылку для скачивания видео.
Как пользоваться

    Откройте видео-пин в Pinterest.
    Нажмите «…».
    Выберите «Получить код для встраивания пина».
    Скопируйте код целиком.

Пример:

<iframe src="https://assets.pinterest.com/ext/embed.html?id=1234567890123456789" height="445" width="345" frameborder="0" scrolling="no"></iframe>

    Вставьте код на странице сайта.
    Нажмите «Найти видео».
    Нажмите «Скачать видео».

Вместо кода можно вставить обычную ссылку на пин или короткую ссылку вида:

https://pin.it/...

Требования

Понадобится Python версии 3.10 или новее.

Проверить установленную версию:

python --version

На macOS и Linux используйте:

python3 --version

Быстрый запуск в Windows

    Установите Python 3.10 или новее.
    При установке обязательно отметьте Add Python to PATH.
    Скачайте репозиторий через Code → Download ZIP.
    Распакуйте скачанный ZIP-файл.
    Дважды нажмите файл start.bat.

Скрипт создаст виртуальное окружение, установит зависимости и запустит приложение. Откройте в браузере:

http://127.0.0.1:5000

Чтобы остановить сервер, нажмите Ctrl+C в терминале.
Быстрый запуск на macOS и Linux

    Скачайте и распакуйте репозиторий.
    Откройте терминал в папке проекта.
    Выполните:

chmod +x start.sh
./start.sh

Скрипт создаст виртуальное окружение .venv, установит зависимости и запустит приложение.

Откройте в браузере:

http://127.0.0.1:5000

Чтобы остановить сервер, нажмите Ctrl+C.

На некоторых дистрибутивах Linux может потребоваться установить модуль виртуального окружения:

sudo apt install python3-venv

Ручная установка

Склонируйте репозиторий:

git clone https://github.com/Maksim645-cuber/Pin-Downloader.git
cd Pin-Downloader

Создайте виртуальное окружение:

python -m venv .venv

На macOS и Linux используется команда python3:

python3 -m venv .venv

Активируйте виртуальное окружение.

Windows:

.venv\Scripts\activate

macOS и Linux:

source .venv/bin/activate

Установите зависимости:

python -m pip install -r requirements.txt

Запустите приложение:

python app.py

На macOS и Linux может потребоваться:

python3 app.py

После запуска откройте в браузере:

http://127.0.0.1:5000

Красное предупреждение This is a development server появляется всегда и не означает ошибку. Сайт рассчитан на запуск на вашем компьютере.
Из чего состоит проект

├── app.py
├── index.html
├── start.bat
├── start.sh
└── requirements.txt

    app.py — Flask-сервер, который ищет видео и передаёт файл.
    index.html — интерфейс сайта.
    start.bat — запуск для Windows.
    start.sh — запуск для macOS и Linux.
    requirements.txt — зависимости проекта: Flask и requests.

Как это работает

В коде встраивания самого видео нет — есть только идентификатор пина.

Сервер:

    Извлекает ID пина.
    Запрашивает данные пина у Pinterest.
    Ищет прямую ссылку на MP4.
    Передаёт найденный файл браузеру.

Скачивать через сервер можно только файлы с серверов Pinterest:

*.pinimg.com

Поэтому приложение не работает как открытый прокси.

Запускать сайт нужно именно через app.py. Если открыть index.html двойным щелчком или через Live Server, поиск видео работать не будет — для него нужен Python-сервер.
Если что-то не работает
Что вы видите 	Что делать
Страница открыта не через app.py или ошибка 404 	Запустите python app.py и откройте http://127.0.0.1:5000
Команда python не найдена 	На Windows используйте py app.py
Команда python3 не найдена 	Установите Python 3.10 или новее
Используется Python старше 3.10 	Обновите Python
Порт 5000 занят 	На macOS или Linux используйте другой порт
Не найден index.html 	Проверьте, что файл находится рядом с app.py
В пине нет видео 	Проверьте, что это именно видео-пин
Видео не находится 	Pinterest мог изменить формат ответа
Порт 5000 занят

Часто порт 5000 занимает AirPlay на macOS. В последней строке app.py замените:

app.run(debug=True)

На:

app.run(debug=True, port=5001)

Затем откройте:

http://127.0.0.1:5001

Видео есть, но не находится

Pinterest периодически меняет внутренние данные пинов.

В терминале появятся строки с сообщением не сработал. При создании Issue приложите эти строки, предварительно удалив личные данные.

Скачивайте видео только при наличии соответствующих прав.

Права на ролики принадлежат их автору. Не публикуйте чужие работы без разрешения.

Проект не связан с Pinterest и не одобрен компанией Pinterest. Использование может нарушать условия сервиса Pinterest — ответственность за использование лежит на пользователе.

Не выкладывайте сервер в интернет в таком виде: app.py использует режим отладки debug=True. Для публичного хостинга отключите режим отладки и используйте продакшен-сервер, например Gunicorn.
